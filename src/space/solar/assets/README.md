# Solar system imagery

Planet and moon maps from NASA's 3D Resources collection
(https://github.com/nasa/NASA-3D-Resources, "Images and Textures"), public
domain: Jupiter, Saturn, Neptune, Pluto, Charon, Titan, Io, Europa, Ganymede,
Callisto, Phobos and Enceladus. Resampled; unmapped (white) areas on Callisto,
Ganymede, Europa and Enceladus filled from the surroundings.

`milkyway.jpg` and the star catalogue in `../stars.ts` were extracted from the
NASA SVS Tycho deep star map in the same collection.
