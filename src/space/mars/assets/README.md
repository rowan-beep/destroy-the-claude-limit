# Mars imagery

`mars_viking_mdim21.jpg`: the Viking MDIM 2.1 colourised global mosaic of Mars
(NASA / JPL / USGS Astrogeology), public domain, resampled to 2880 x 1440,
equirectangular from 180 W.
Source: https://commons.wikimedia.org/wiki/File:Mars_Viking_MDIM21_ClrMosaic_1km.jpg

`public/hires/mars_8k.jpg`: the same Viking MDIM 2.1 colour mosaic at
8192 x 4096 (2.6 km a pixel), assembled from NASA's Mars Trek tile service
(layer Mars_Viking_MDIM21_ClrMosaic_global_232m, zoom 4); public domain.
Fetched at run time where the graphics card takes 8192-pixel textures.

# Earth imagery (public/hires)

- `earth_8k.jpg`, `earth_4k.jpg`: NASA Blue Marble Next Generation with
  topography and bathymetry, December 2004 (NASA Earth Observatory / Reto
  Stöckli), resampled from 21600 x 10800. Public domain.
- `earth_night_4k.jpg`: NASA Black Marble 2016 (NASA Earth Observatory / Joshua
  Stevens, Suomi NPP VIIRS), greyscale, resampled. Public domain.
- `earth_clouds_4k.jpg`: NASA Blue Marble cloud composite, resampled. Public domain.
